# 地域経済（新潟）活性化の効果最大の起爆剤

Nov 15, 2026 · @keythrive

本記事は「地域課題×生成AI×ナッジ実験」Advent Calendar の一部です。

地域課題を解決する前に、まず地域課題に関心を持つ。

本シリーズでは、生成AIを活用して短期間で試作したアプリケーションを通して、地域住民が課題を自分事として考えるきっかけづくりを試みています。

## はじめに

新潟県の人口は2010年代から一貫して減り続けている。令和7年（2025年）の賃金構造基本統計調査では、所定内給与額は月291.8千円、全国33位。東京の69.8%、富山よりも月1.3万円低い。

「新潟の強みを活かす」という議論は何十年も繰り返されてきた。コシヒカリ、日本酒、燕三条の職人技、豊富な雪山。それが悪いわけではない。しかし人口流出は止まらない。若者は東京へ向かう。高齢化率は全国平均を上回り、求人は余っているのに来る人がいない。

問題の本質はどこにあるのか。「強みを磨く」という正攻法が効かないとすれば、まったく別の切り口が必要ではないか。

そこで試みたのが、データと生成AIを使った「逆張り分析」だ。新潟の「当たり前」をいったん脇に置き、全国47都道府県のクラスタリング分析と、アジア太平洋13ヵ国との国際比較から、新潟の「異質さ」を探った。

## なぜこのアプリを作ったのか

「課題はわかっている。でも解決策が見えない」という声を聞くたびに感じていた違和感がある。

本当に課題の構造をデータで確認したことがあるのか、ということだ。

新潟の問題が「魅力の欠如」なのか「情報の非対称性」なのか「賃金格差」なのかによって、打つべき手はまったく異なる。今回、SSDSE（統計センターの都道府県別データ）とWorld Bank APIを組み合わせて分析した結果、浮かび上がった事実がひとつある。

**「求人倍率は全国平均より1.5標準偏差高いのに、転入率は1.6標準偏差低い」** ——つまり、仕事はあるのに人が来ない。この逆説が、新潟の問題を「魅力がない」という曖昧な話で終わらせてはいけない根拠だ。

分析をさらに国際スケールに広げると、新潟はドイツ（製造業×R&D×高賃金のMittelstand）に最も近い構造を持ちながら、FDI（外国直接投資）流入率はシンガポールの25分の1という現実も見えてきた。

このアプリは、そうした「データが語る新潟の逆説」を可視化し、議論の起点を作るために試作した。

## どんなアプリか

`niigata_innovation bigbang` は、Jupyter Notebookをベースにした対話型データ分析ツールだ。

3つのフェーズで構成されている。

**Phase 1 — 国内クラスタリング**

SSDSE-B（統計センター、県別推移2025年版）から21指標を抽出し、47都道府県をUMAP＋HDBSCANでクラスタリング。LOF（Local Outlier Factor）で各県の「異質度スコア」を算出する。新潟が「青森・秋田・山形と同じグループ」に属しながらも、求人倍率だけが突出して高いことが一目でわかる。

**Phase 2 — 国際比較（e-Stat + World Bank API）**

**Phase 2A — e-Stat API** — 賃金構造基本統計調査（令和7年）・工業統計・商業統計を取得。産業別・規模別の賃金格差を可視化し、どの産業分野で新潟の賃金が特に低い（または高い）かを特定する。

**Phase 2B — World Bank Open Data** — アジア主要10ヵ国（日本・韓国・台湾・タイ・ベトナム・中国・シンガポール・マレーシア・インドネシア・フィリピン）のGDP・製造業比率・人口成長率・失業率を取得。新潟の産業構造と最も親和性の高い国・地域を定量化する。

World Bank APIで13ヵ国×12指標を取得し、新潟を日本の代理値として国際座標に投影。シンガポール・韓国・ドイツとの距離を定量化する。新潟の高齢化率は国際Zスコア+1.97——13ヵ国中ダントツ1位だが、これは「弱点」ではなく「最先進事例」として読み替えられる。

**Phase 3A/3C — 賃金・ FDI戦略生成**

**Phase 3A — 賃金ギャップの可視化** — 令和7年賃金構造基本統計調査（参考表1）を読み込み、47都道府県を所定内給与額で並べた棒グラフと、新潟の推定年収（約280万円）vs 東京（約401万円）の比較を表示する。

**Phase 3C — FDIターゲットマトリクス（LLM生成）** — Zスコア分析・クラスタリング結果・賃金ギャップデータをまとめてClaude APIに渡し、JSON形式でFDI誘致戦略を自動生成する。3大ターゲット産業：食品加工×台湾・タイ、製造業R&D拠点×東京補完、デジタルリモート拠点が導かれる。

**Phase 2C — LLM統合戦略仮説生成** — Phase 1〜2Bの全分析結果（クラスター要約・Zスコア・賃金ギャップ・アジア比較）を1つのプロンプトに統合しClaude APIに渡す。政策提言・ナッジ設計・富山モデル移植の具体的アクションプランをmax\_tokens=4,096で生成しintegrated\_strategy.txtに保存する。

Zスコアとクラスタリング結果をプロンプトに変換し、Claude APIで具体的な政策・FDI誘致アイデアをJSON形式で生成。賃金データ（令和7年賃金構造基本統計調査）を加えて、「東京比69.8%の賃金格差」を織り込んだ現実的な戦略に落とし込む。

## 実際に触ってみる

GitHub からノートブックを取得して、ローカルのJupyter環境で動かすことができる。

```bash
git clone https://github.com/keith-river/innovative_niigata
cd innovative_niigata
pip install umap-learn hdbscan plotly scikit-learn pandas requests
jupyter notebook niigata_positioning.ipynb
```

分析に使うデータはすべて公開統計からの取得だ。

- **SSDSE-B-2025.csv** — 統計センター「教育用標準データセット 県別推移」を[公式サイト](https://www.nstac.go.jp/use/literacy/ssdse/)からダウンロードしてノートブックと同じフォルダに置く
- **World Bank API** — 無料・登録不要。セルを実行するだけで自動取得される
- **e-Stat 賃金データ** — 厚生労働省「賃金構造基本統計調査 参考表」を[e-Stat](https://www.e-stat.go.jp/)からダウンロードして同フォルダに置く
- **Claude API**（Phase 3のみ）— Anthropicコンソールでキーを取得し、環境変数 `ANTHROPIC_API_KEY` にセット

## 触ってみて考えてほしいこと

UMAPマップを開いたとき、新潟がどのクラスターに属しているかを確認してほしい。「東北型」のグループに入りながら、求人倍率だけが突出しているという事実を、あなたはどう読むか。

**「仕事はある。でも人が来ない」は誰の責任か？**

県外から見ると新潟の求人情報は届いていない。移住を考える人が検索しても、賃金水準が東京の70%であることは最初からわかる。これは「魅力の問題」なのか、「賃金の問題」なのか、「見せ方の問題」なのか。

ナミックス株式会社という新潟発の企業が、半導体封止材で世界シェア40%を持ち、売上の9割を海外で稼いでいる事実がある。「新潟から世界へ」は不可能ではない。ではなぜ、この成功パターンが他社に広がらないのか。

**あなたに問いたいことは3つある。**

- 新潟の「保守的な文化」は本当に障壁か。それとも、外からの血を受け入れれば「安定して長く働ける」という強みに変わるのではないか
- 東京比70%の賃金を「安い」と見るか、「東京のコストの70%でアジアにアクセスできる製造拠点」として外資に売り込む材料と見るか
- 分析が示す「最類似国＝ドイツ」という結果を、新潟はどう使うべきか。ドイツ型Mittelstand（中小精密製造業が高賃金・高輸出を両立するモデル）は、燕三条に移植できるか

このノートブックが出す答えはひとつではない。クラスタリングのパラメータを変えれば結果も変わる。大切なのは「データを見て自分で考える」という行為そのものだ。

あなたが新潟に住んでいるなら、あるいは新潟を離れた経験があるなら——数字はあなたの実感と一致していたか？

## Phase 2C 出力サンプル — LLMが導いた戦略仮説

Phase 2Cでは、クラスタリング・Zスコア・賃金ギャップ・アジア比較の全結果を1つのプロンプトに統合し、`claude-opus-4-5` に戦略立案を委ねた。以下は実際の出力から抜粋した核心部分だ。

**構造的ポジション定義（LLM生成）**

> 「求人過剰×人口流出」の逆説県 — 仕事はあるが選ばれない、東京の対極に位置しながら補完関係を持つ製造業立地。

**5年以内の即効策（LLM生成）**

1. **富山モデル移植** — 距離3.46の最近傍・富山県の成功パターン（出生率1.46・製造業×観光）を参照。KPI: 合計特殊出生率 1.21 → 1.35
2. **賃金底上げ補助金** — 全国比85.7%×転入率−1.64σの直接因果に対処。KPI: 転入者数 +5,000人/年
3. **求人シグナルの国際発信** — 求人倍率+1.46σをFDI誘致に転用。KPI: 外資系企業立地 +10社（5年累計）

**ナッジ設計（行動経済学的アプローチ）**

- **デフォルト変更** — 求人票に「新潟勤務＋リモート可」を標準表記化。選択コストをゼロに。
- **社会的証明** — 移住者の「月収＋生活費」可処分所得を可視化。東京比で「手取りが増える」事実を先行提示。
- **損失回避フレーム** — 「今来れば初年度家賃0円」ではなく「今来ないと枠が埋まる」限定フレームで転入促進。

この出力はあくまで仮説の出発点だ。データのパラメータを変えれば結論も変わる。重要なのは「なぜその指標が動くのか」を人間が検証するプロセスだ。

## 技術メモ

## 生成AI活用について

本アプリの課題設定と設計思想は筆者自身が行った。「新潟の問題の本質をデータで見たい」「従来の強みからいったん離れた分析がしたい」という問いは、筆者が地域の現状を見て感じた問題意識から生まれたものだ。

コードの実装はClaude（生成AI）との対話を通じて進めた。分析の各ステップで生成されたコードをレビューし、エラーへの対処や設計の改善を繰り返した。LLMによる戦略仮説生成セクション（Phase 3）では、プロンプト設計と出力の批判的評価も筆者が担った。

最終的な動作確認と記事の内容確認は筆者が行っている。生成AIはあくまでプロトタイピングの速度を上げるための道具として使った。

## 留意事項

- 個人情報は一切含まない。使用データはすべて公開統計（SSDSE-B、World Bank API、e-Stat）
- 分析結果はパラメータ設定（UMAPのn\_neighbors、HDBSCANのmin\_cluster\_sizeなど）に依存する。ひとつの解釈として参照されたい
- 本アプリは試作版（プロトタイプ）である。意思決定の根拠として単独で使用することは想定していない
- 議論の起点として公開している。結論の提示ではなく、問いの共有が目的だ

## おわりに
